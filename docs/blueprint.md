# **App Name**: CourseCraft Academy

## Core Features:

- Course Listing: Intuitive process for creators to list courses, using external video URLs and rich descriptions.
- Course Browsing and Search: Learners can easily browse courses by category, search by keywords, and view detailed course previews.
- Secure Course Purchasing: Enable secure in-app purchasing of courses using Stripe.
- Course Library: A dedicated area for learners to access all purchased courses.
- AI-Powered Course Recommendation Tool: LLM analyses the learner's past purchases and browsing history, then offers course recommendations accordingly.
- AI Course Outline Suggestion Tool: Creators use the built-in AI to suggest course outlines and topic breakdown to jumpstart their content creation. It will reason when to suggest incorporating modern pedagogy tools into their suggestions.

## Style Guidelines:

- Primary color: Warm blue (#64B5F6), evoking trust and professionalism.
- Background color: Light desaturated blue (#E3F2FD), maintaining a calming and modern feel.
- Accent color: Soft orange (#FFAB91), adding warmth and highlighting calls to action.
- Headline font: 'Poppins', sans-serif, providing a geometric and contemporary look.
- Body font: 'Inter', sans-serif, ensuring readability and a neutral feel.
- Use clean, modern icons to represent course categories and actions, enhancing usability.
- Subtle transitions and animations on course cards and page loads, adding a professional touch.
